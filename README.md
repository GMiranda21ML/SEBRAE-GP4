Esta aplicação web foi desenvolvida para a cadeira **Projetos 3** da **CESAR School**, em que tivemos como cliente o **SEBRAE**, entidade que impulsiona o empreendedorismo e promove a competitividade das micro e pequenas empresas no Brasil.

Nosso projeto visa facilitar a coleta de inteligência de dados e o engajamento com o público, oferecendo uma plataforma completa para criação, edição e disparo de pesquisas personalizadas por e-mail.
Além disso, o sistema conta com funcionalidades de análise de dados administrativa e um Mural interativo, permitindo uma comunicação direta e a visualização centralizada de feedbacks e informações entre os administradores e os usuários.

## 🛠️ Principais Funcionalidades da solução

### **Gestão Completa de Pesquisas**
- Criação, edição e exclusão de formulários personalizados.
- Suporte a múltiplos tipos de perguntas: Texto, Múltipla Escolha e Sim/Não.
- Configuração de perguntas obrigatórias e personalização de opções.

### **Automação de Disparos e Comunicação**
- Disparo automático de convites para responder pesquisas via E-mail para a base de usuários.
- Integração com serviço de e-mail (JavaMailSender) para notificações.

### **Portal do Usuário e Administrador**
- Sistema de autenticação (Login) e Cadastro com diferenciação de perfis (Admin e User).
- Mural interativo para usuários visualizarem pesquisas disponíveis e acessarem os formulários de resposta.
- Painel administrativo para controle de conteúdo e monitoramento.

### **Coleta e Análise de Dados**
- Interface para preenchimento e envio de respostas pelos usuários.
- Visualização administrativa de pesquisas e feedbacks (Mural e Análise).
